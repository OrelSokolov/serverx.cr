# Server X

> ⚠️ **ЭКСПЕРИМЕНТ. НЕ ДЛЯ ПРОДАКШЕНА.** Это исследовательский проект для
> проверки одной гипотезы, а не фреймворк. API, форматы и поведение меняются
> без предупреждения.

Экспериментальный HTTP-сервер для Crystal, построенный по nginx-модели.
Гипотеза: если убрать per-request аллокации из транспортного слоя, сервер на
базе fiber + event loop (архитектура stdlib Crystal) догоняет nginx по RPS —
при сохранении обычного синхронного стиля кода.

## Архитектура

- **Один буфер (64 KiB) на соединение** — единственная аллокация за всю жизнь
  соединения; между keep-alive-запросами переиспользуется.
- **Offset-парсер HTTP/1.1** — заголовки и значения не превращаются в строки:
  парсер расставляет смещения по буферу (как state machine nginx). Keep-alive,
  пайплайнинг, регистронезависительные `Connection`/`Content-Length`, drain
  тел больше буфера, 431 на переполнение заголовков.
- **Master/worker через `SO_REUSEPORT`** — воркеры однопоточные
  (`-Dwithout_mt`), ядро балансирует соединения, мастер перезапускает
  погибших воркеров. Ровно схема nginx.
- **Метрики в рантайме**: `# stats`-строка с reqs, RSS и **gc_win_kb** —
  сколько мусора намыл GC за окно (главная метрика проекта).

## Результаты (полный отчёт: [RESULTS.md](RESULTS.md))

22 ядра (Intel Ultra 7 155H), wrk `-t11`, медиана 3×10s, ответ 13 байт:

| Конфигурация | RPS | GC churn (намыв мусора) |
|---|---|---|
| stdlib `HTTP::Server`, 8 воркеров | 932k | **70–110 МБ/с** |
| **Server X, 8 fork-воркеров** | **1 126k** | **0.2–1.5 МБ/с** |
| nginx (docker, host network), auto | 1 075k | — (нет GC) |

Выводы: zero-alloc даёт +15–50% RPS и снижает GC-нагрузку в 70–370 раз;
fork + `SO_REUSEPORT` обгоняет многопоточный планировщик Crystal в 5 раз;
на динамическом ответе — паритет с nginx. stdlib намывает **~600–700 байт
мусора на каждый запрос**, без остановки, весь срок жизни процесса.

## Запуск

```sh
crystal build --release -Dwithout_mt -o bin/serverx src/serverx.cr

./bin/serverx --impl pooled --workers 8 --port 4500   # сервер
curl localhost:4500/                                   # -> Hello, World!

./bench.sh                                             # полный бенчмарк (~10 мин)
```

Зависимостей нет — только stdlib. Для nginx-сравнения нужен docker.

## Ограничения (осознанные, для эксперимента)

- Это транспортный слой: нет роутера, хендлеров, TLS, таймаутов соединений.
- Заголовки ≤ 64 KiB; запросы с `Transfer-Encoding: chunked` не
  поддерживаются; после drain большого тела пайплайновые байты отбрасываются.
- `--workers > 1` требует сборки `-Dwithout_mt` (fork несовместим с MT-режимом
  Crystal 1.21); многопоточный режим — сборка без флага + `CRYSTAL_WORKERS`.
